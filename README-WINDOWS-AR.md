# Saudi Legal AI — Windows 10/11

## تشغيل تجريبي بنقرة مزدوجة
1. ثبّت Python 3.11 أو أحدث على Windows مع تفعيل خيار Add Python to PATH.
2. فك ضغط الحزمة إلى مجلد يمكن الكتابة فيه.
3. انقر مرتين على `تشغيل-Saudi-Legal-AI.bat`.
4. في أول تشغيل تُثبت المكتبات تلقائيًا؛ ثم تفتح الواجهة على `http://127.0.0.1:8000/`.
5. اترك نافذة التشغيل مفتوحة أثناء الاستخدام. لإيقاف البرنامج أغلق النافذة.

## إنشاء Setup.exe
1. ثبّت Python 3.11+ و Inno Setup 6.
2. انقر مرتين على `build_windows.bat`.
3. بعد نجاح البناء سيظهر `dist-installer\SaudiLegalAI-Setup-Windows.exe`.

**تنبيه:** ملف Setup.exe لم يتم بناؤه أو اختباره في هذه البيئة؛ يجب تنفيذ خطوة البناء على Windows. ملف BAT للتشغيل التجريبي يحتاج Python مثبتًا. الحزمة ليست جاهزة للاستخدام القانوني الإنتاجي، ولا تتضمن قاعدة أنظمة سعودية كاملة أو مصادقة أو تشفيرًا للبيانات. لا تدخل معلومات عملاء سرية.
