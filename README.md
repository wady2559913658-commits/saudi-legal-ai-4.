# Saudi Legal AI v1.1 — Starter Project

## التشغيل
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
source .venv/bin/activate
pip install -r requirements.txt
python -m scripts.seed_demo
uvicorn backend.main:app --reload
```
لوحة التحكم: http://127.0.0.1:8000/  
توثيق API: http://127.0.0.1:8000/docs

## إضافات v1.1
- واجهة عربية RTL لإنشاء القضايا والبحث في corpus.
- سجل روابط اكتشاف المصادر الرسمية.
- استيراد محكوم لنسخ المواد القانونية من ملف JSON محلي.
- رسم معرفي أولي يربط النظام بمواده.
- نقطة API للتحقق من سريان نسخة المادة بتاريخ الواقعة.

## استيراد مواد موثقة
1. انسخ `data/corpus-import-example.json` واستبدل القيم بمحتوى رسمي تم التحقق منه.
2. تحقق من المصدر وتاريخ النشر والنفاذ والتعديلات والإلغاء والأحكام الانتقالية.
3. احسب SHA-256 للنص الأصلي.
4. نفّذ:
```bash
python -m scripts.import_corpus_json data/your-verified-articles.json
```
المستورد لا يزحف إلى المواقع ولا يثبت صحة الوثيقة قانونيًا؛ السماح بالنطاق مجرد فحص أولي للمضيف.

## بوابات رسمية للبحث والتحقق
- هيئة الخبراء: https://laws.boe.gov.sa/
- بوابة تشريعات وزارة العدل: https://laws.moj.gov.sa/
- وزارة الموارد البشرية: https://www.hrsd.gov.sa/
- جريدة أم القرى: https://uqn.gov.sa/
- المنصة الوطنية الموحدة: https://my.gov.sa/en/rules

## حدود النسخة
لا تتضمن هذه الحزمة قاعدة تشريعات سعودية كاملة، ولا مزامنة تلقائية أو سجل تعديلات موثقًا. لا تستخدمها لإصدار استنتاج قانوني دون مراجعة النص الرسمي ومحامٍ مختص. لا تدخل بيانات عملاء سرية قبل تنفيذ المصادقة والصلاحيات وعزل المستأجرين والتشفير وسياسات الاحتفاظ واختبارات الأمن.

## متطلبات ما قبل الإنتاج
PostgreSQL، هوية وصلاحيات RBAC، عزل الجهات، تشفير، OCR وفحص ملفات، تطبيع عربي قانوني، بحث متجهي فعلي وإعادة ترتيب، لقطات مصادر موثقة، مقارنة تعديلات، مراقبة ونسخ احتياطية واختبارات اختراق ومسار مراجعة بشرية.
